# SmartStay - No Composer
A PHP + MySQL rental platform with room discovery, owner listing, booking, demo advance payment, automatic rental agreement storage and PDF download. No Composer or third-party PHP library is required.

## Install
1. Copy the `smartstay` folder to `C:\xampp\htdocs\`.
2. Start Apache and MySQL.
3. In phpMyAdmin import `database/schema.sql`.
4. Open `http://localhost/smartstay/`.
5. Tenant: register normally. Owner demo: `owner@smartstay.test` / `password`.

The PDF is generated by a small pure-PHP PDF writer in `agreement_pdf.php`.
